# 提示词工程 · Gestalt

Chrome 侧边栏 AI 提示词生成器：用一句话说清需求，直接得到一条可复制、可直接使用的专业提示词。

## 功能

- 一次成稿：不反问、不闲聊，只输出成品提示词；缺失信息用领域默认值补齐，并在末尾附一行「已假设：」
- 11 个内置技能：图片、视频、音乐音频、写作文案、代码任务、翻译、角色设定、数据抽取、智能体系统提示词、提示词优化、通用兜底
- 两段式自动路由：先判断该用哪个技能，再按该技能的方法论生成；修改类追问沿用当前技能，路由失败静默回退到「通用」
- 可手动锁定技能、重新生成、流式输出、一键复制
- 多模型管理：任意 OpenAI 兼容接口（Base URL + API Key + 模型 ID），支持测试连接、导出/导入数据
- 两种打开方式：Chrome 侧边栏，或独立小窗
- 划词右键「用 Gestalt 生成提示词」；快捷键 `Alt+G` 打开面板
- 输出语言可选：跟随输入 / 简体中文 / English

## 技术栈

React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · CRXJS · Chrome Manifest V3

## 本地开发

```bash
npm install
npm run dev     # 开发模式
npm run build   # 构建到 dist/
```

## 在 Chrome 中加载

1. 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择构建产物 `dist/` 目录
4. 点击工具栏图标或按 `Alt+G` 打开面板

## 使用

1. 设置 → 模型 → 添加模型，填写 Base URL、API Key、模型 ID，点「测试连接」
2. 在输入框描述需求（例如「给我的咖啡店写一篇小红书开业文案」）
3. 生成后点复制即可直接使用

## 隐私

API Key 仅保存在浏览器本地（`chrome.storage.local`），请求由扩展直接发往你配置的模型接口，不经过任何中转服务器。
